# Feira-BeachPet
O projeto BeachPet é um quísosque praiano onde abraçamos por completo os pets, incluindo produtos feitos especificamente para eles.
Cada compra feita no nosso site tera parte do dinheiro ser doado para ongs dedicados a animais e abrigos para podermos auxiliar nos cuidados.

# Nós temos:
- Um sistema de login, para usuários logarem e a administração ter maior controle
- Um painel geral, mostrando o estoque de produtos, total feito em vendas, total de dinheiro doado e o valor médio de compras
- Um sistema de estoque diretamente ligado ao MySql, mostrando quantos produtos temos no estoque, podendo ser editado caso tenha uma falha
- Um caixa onde clientes podem comprar/encomendar os produtos, tendo um sistema de caixa e valor de compra.

  Usamos o MySql para auxiliar no nosso sistema de estoque, facilitando a atualização de dados.
  Usamos Front-end e Back-end para dar funcionalidade para o nosso site.
  E utilizamos HTML para fazer o nosso site em si.
